AgriTech Web CI/CD Pipeline

Phase 1: Source Control Management (SCM)
Developers commit HTML and JavaScript algorithm updates to the main branch on GitHub.
Phase 2: Continuous Integration (CI)
GitHub Actions automatically provisions an ubuntu-latest runner to verify all application files exist and pass integrity checks.
Phase 3: Continuous Deployment (CD)
Once verification succeeds, artifacts are packaged and deployed live to GitHub Pages with zero downtime.
